## Prompting Strategy

Throughout development we followed an incremental AI-assisted workflow.

For every sprint:

1. Define the engineering task.
2. Review existing project documentation.
3. Generate only the required feature.
4. Manually review generated code.
5. Test locally.
6. Commit using incremental Git commits.
7. Update AI usage logs and project memory.

Large one-shot code generation was intentionally avoided.
